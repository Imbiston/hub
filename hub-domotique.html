🔍 Découverte d'appareils

Bluetooth : le navigateur utilise l'API Web Bluetooth (Chrome / Edge). Tu choisis l'appareil dans la fenêtre de sélection du système — c'est une sécurité imposée par le navigateur, aucun scan passif furtif n'est possible.
WiFi & réseau local : les navigateurs interdisent de scanner le réseau. Le bouton « Scanner le réseau local » passe par le pont local (onglet 🌉), un petit script Python qui tourne sur ton PC et fait le vrai scan (ping sweep + mDNS).

📺 Télécommande Fire TV

Sur ton Fire TV : Paramètres → My Fire TV → Options pour développeurs → ADB debugging : Activé, puis note l'adresse IP (Paramètres → My Fire TV → À propos → Réseau). Le pont local enverra les touches via ADB (input keyevent). Sans pont, les touches ne peuvent pas partir du navigateur.

🔊 Contrôle Alexa

Amazon n'offre aucun accès direct à un Echo depuis un navigateur : il faut passer par le cloud Amazon. Deux voies possibles :
1️⃣ Skills / Routines — crée une routine « ouverte » (ex : « Alexa, allume le salon ») et déclenche-la ici via le pont local qui parle à un endpoint Skill ou à Home Assistant + Alexa Media Player.
2️⃣ Web ouvert — raccourcis vers l'app Alexa web pour gérer tes appareils manuellement.

🎧 AirPods Max

⚠️ Réalité technique : les AirPods Max utilisent le Bluetooth Classic + un protocole Apple privé (AAP/L2CAP). Un navigateur ne peut ni s'y connecter ni les piloter (pas de GATT standard, Apple bloque l'appairage navigateur). Ce panneau sert de tableau de bord : état, batterie (saisie manuelle ou via pont + macOS), et raccourcis vers les réglages.

🌉 Pont local

Le pont est un mini-serveur Python à lancer sur ton ordinateur (même réseau que tes appareils). Il donne au navigateur les super-pouvoirs manquants : scan réseau, ping, contrôle ADB Fire TV. 1️⃣ Clique sur « Télécharger le pont » — 2️⃣ python pont.py — 3️⃣ connecte-le ci-dessous.
